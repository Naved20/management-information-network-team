# MINT Design Guide

## 1. Brand Direction

MINT is positioned as a premium technology and innovation community for students. The visual language should feel:

- modern
- serious
- intelligent
- student-driven but professional
- minimal and confident

The overall tone is not playful or over-styled. It feels more like a high-trust startup or innovation ecosystem than a basic college club website.

---

## 2. Core Design Philosophy

### Product-style clarity
- Strong visual hierarchy
- Spacious layouts
- Clean typography
- Minimal distractions
- Clear information blocks

### Premium minimalism
- Mostly black, white, and soft neutral tones
- One accent color is used intentionally
- Good whitespace is treated as a design asset
- Card layouts are structured but not crowded

### Tech-community feel
- The design avoids generic “college poster” visuals
- It leans into digital, analytical, modern energy
- Abstract geometric patterns are used to suggest innovation, systems, and networking

---

## 3. Color Palette

### Primary palette

| Role | Hex | Usage |
|---|---:|---|
| Background | #F7F8F6 | Main page background |
| White / Panel | #FFFFFF | Cards, panels, elevated surfaces |
| Text | #111111 | Primary text |
| Muted Text | #6B7280 | Secondary text |
| Dark Surface | #0B0F0D | Feature blocks, dark CTA areas |
| Mint Accent | #22C55E | Primary highlight and brand energy |
| Mint Strong | #16A34A | Hover / stronger brand emphasis |
| Mint Soft | rgba(34, 197, 94, 0.12) | Soft accent backgrounds |
| Border | rgba(17, 17, 17, 0.08) | Dividers and subtle outlines |

### Color behavior
- White and off-white create clean, premium readability.
- Black and deep charcoal give the site authority and seriousness.
- Mint green is used as the main signature accent to make the brand memorable without being loud.
- The accent is used sparingly to preserve a premium look.

### Emotional meaning
- White + black = clarity, confidence, credibility
- Mint = growth, innovation, sustainability, tech energy
- Neutral grays = balance and calm professionalism

---

## 4. Typography

### Font direction
The interface uses a clean modern sans-serif style, inspired by geometric tech fonts such as Geist / Inter-like systems.

### Heading language
- Large, bold, high-contrast headings
- Negative tracking for a premium editorial feel
- Strong scale differences between hero + section titles + body copy

### Body copy
- Comfortable line-height
- Good readability with muted gray text
- Minimal decorative styling

### Typographic rhythm
- Hero headline: huge, stripped-down impact
- Section headers: large and confident
- Body text: clean and readable
- Labels: uppercase micro-text with spacing for structure and clarity

---

## 5. Layout System

### General structure
- Max width: around 1200px
- Container padding: roughly 24–32px on smaller screens
- Spacious vertical rhythm between sections
- Clear module separation using cards, borders, and negative space

### Section spacing
- Hero: generous top spacing
- Sections: comfortable padding with major whitespace
- Cards: soft-radius containers with subtle shadows

### Border radius
- Buttons: pill-shaped (999px)
- Cards and panels: 18px–32px
- Visual containers: 24px–32px

### Shadows
- Minimal and soft
- Used only to give depth to cards and feature panels
- Never heavy or flashy

---

## 6. UI Elements

### Header / Navigation
- Sticky top navigation
- Minimal links with subtle hover underline effects
- Primary CTA button on the right
- Clean brand lockup with logo + wordmark

### Hero section
- Big statement headline
- Short supporting paragraph
- Two CTA buttons
- Abstract network / system graphic on the right
- This section communicates identity and vision immediately

### Philosophy / value blocks
- Four cards representing core values
- Strong labels like “Learn”, “Connect”, “Create”, “Lead”
- Compact, easy-to-read content blocks

### Domain section
- Grid-based card layout
- Each card has a numbered index and short descriptive text
- Good for communicating the club’s many focus areas without clutter

### Event cards
- Structured cards with category tag + description + call-to-action
- Helps the site feel active and community-centered

### Team section
- Clear member cards
- Avatar-like initials circles
- Clean labels like Founder, President, Faculty Coordinator

### Join CTA section
- A direct conversion moment
- High-contrast dark panel with strong CTA actions
- Feels like a real community invitation, not a generic form dump

---

## 7. Visual Style Details

### Patterns and graphics
- Abstract circular line systems to mimic networking, systems thinking, and connections
- Used as high-end technology visuals without being too busy
- Decorative elements are subtle and secondary to the content

### Glassmorphism usage
The design uses subtle glass-like layers only in moderation, not as the main visual language. This keeps the website premium and modern without becoming overdone.

### Overall mood
- Calm, serious, intelligent, future-facing
- Technology-first but student-friendly
- Premium enough to feel like a real organization, not a school poster

---

## 8. UX Principles

### 1. Immediate clarity
The user should understand the club’s purpose within seconds.

### 2. Strong hierarchy
Headlines, labels, spacing, and cards guide attention naturally.

### 3. Trust and professionalism
The site should look like a credible innovation ecosystem, not a casual event page.

### 4. Mobile-first comfort
Content stacks cleanly, navigation remains usable, and spacing adapts comfortably on smaller screens.

### 5. Conversion-focused action
Buttons and CTAs are clear and repeated in context without feeling pushy.

---

## 9. Design Summary

The MINT website is built around a premium tech-community aesthetic using:

- white/off-white backgrounds for clarity
- black/dark surfaces for strength and contrast
- mint green as an intentional brand accent
- large modern typography
- spacious layout structure
- controlled card-based architecture
- modern network/tech-inspired abstract visuals

The result feels polished, credible, and growth-oriented—appropriate for a serious student innovation and leadership platform.

---

## 10. Suggested Future Enhancements

- Add smoother animation on scroll and hover states
- Add a dedicated Join page with full form and checklist
- Add project highlights / portfolio section
- Add real sponsor, partner, or alumni logos
- Create a dark/light theme toggle if needed in future iterations

This design system can be extended without changing the core identity: premium, focused, and technology-driven.
